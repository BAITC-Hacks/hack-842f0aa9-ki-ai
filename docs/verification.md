# Тапсыру нұсқасын тексеру

Күні: 2026-09-23. Тармақ: `codex/delivery-upgrade`.

## Орындалған тексерулер

Windows, Python 3.12.6. Жұмыс қалтасынан бөлек таза код көшірмесі және жаңа
виртуалды орта қолданылды; бұрынғы `.venv` көшірілген жоқ. Орнату pip кэшіндегі
дистрибутивтерді пайдаланды. Нақты үш Parquet локал көшірмеге бөлек қосылды.

| Тексеру | Нәтиже |
|---|---|
| `python -m pip install -r requirements.txt` | Сәтті орнатылды |
| `python -m pip check` | Қайшы тәуелділік жоқ |
| `python -X utf8 -m unittest discover -v` | 35 тест өтті |
| `python pipeline.py --data data --out out` | 1.193 секунд, барлық алты CSV |
| `python checks/check_outputs.py --out out --data data` | Барлық тексеру өтті |
| Streamlit AppTest, нақты дерек | Карточка, чат, дереккөздер, 7 жүктеу қатесіз |
| Синтетикалық деректе екінші толық есептеу | Алты CSV байт бойынша бірдей |

Нақты шығыс: `nodes_roles` — 2248, `clusters` — 88, `top_nodes` — 20,
`node_metrics`, `node_insights`, `ranking_stability` — әрқайсысы 2248 жол.
19 оқшауланған клиент жоғалмайды. 64 салмақ нұсқасы кінә ықтималдығын есептемейді.
Уақыт — осы компьютердегі бір өлшем; басқа компьютерге кепіл емес.

Тесттер: рөлдер мен score, gid дәлдігі, кластер мүшелігі, топ-лист,
себеп/шектеу/келесі қадам, тұрақтылық, түйінді алып тастау, CSV келісімі,
қайталанғыштық, жетіспейтін/қате файлдар және чат тарихын тазарту.
Автотесттер нақты деректерді қажет етпейді; CI-ге бастапқы Parquet жіберілмейді.

## GitHub Actions

Workflow Python 3.12 және 3.13, Ubuntu ортасында push/PR үшін бапталған.
Бұл жергілікті тексеру Linux немесе Python 3.13 нәтижесін растамайды.

Алдыңғы [Actions іске қосылуы](https://github.com/BAITC-Hacks/hack-842f0aa9-ki-ai/actions/runs/35851679058)
ұйым аккаунтының billing шектеуінен басталмады. Хабарлама:
«The job was not started because your account is locked due to a billing issue.»
Бұл тесттің орындалып, құлағанын білдірмейді; hosted CI өткен деп көрсетілмейді.
Аккаунт иесі шектеуді шешкен соң PR checks қайта орындалуы керек.

## Тапсыру материалдары

Код, қазақша README, Mermaid архитектурасы, әдістеме және тесттер GitHub-та
сақталады. `out/submission.zip` — тек алты нәтиже CSV-інен тұратын жергілікті
архив; бастапқы Parquet пен API кілттері кірмейді. Архивті қайта жасау командасы
README-де бар. Нақты деректер мен нәтиже архиві репозиторийге жарияланбайды.

Көмекші — CSV-ге негізделген offline анықтамалық. Сыртқы LLM шақыруы,
генеративті жауап, табиғи тілден граф сұрауын құру іске асырылмаған.
