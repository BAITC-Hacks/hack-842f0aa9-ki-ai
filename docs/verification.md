# Тапсыру нұсқасын тексеру

Күні: 2026-09-23. Тексерілген код: `main`, commit `45b6330`.

## Орындалған тексерулер

Windows, Python 3.12.6. GitHub-тағы `main` тармағы бос уақытша қалтаға
`git clone --branch main --single-branch` арқылы алынды. Жаңа виртуалды орта
жасалды; бұрынғы `.venv` және дайын `out/` көшірілген жоқ. README-дегі орнату
командасы pip кэшіндегі дистрибутивтерді пайдаланды. Ұйымдастырушы берген үш
Parquet бөлек қосылып, нәтижелер жаңадан есептелді. API кілті көшірілген жоқ.

| Тексеру | Нәтиже |
|---|---|
| `python -m pip install -r requirements.txt` | Сәтті орнатылды |
| `python -m pip check` | Қайшы тәуелділік жоқ |
| `python -X utf8 -m unittest discover -q` | 48 тест өтті, 9.085 секунд |
| `python -X utf8 pipeline.py --data data --out out` | 0.984 секунд, барлық алты CSV |
| `python checks/check_outputs.py --out out --data data` | Барлық тексеру өтті |
| Браузер, таза көшірме, нақты дерек | Топ-20, тұрақтылық, клиент карточкасы, түйінді алып тастау, offline чат және дереккөздер жұмыс істеді |
| Браузердегі `top_nodes.csv` жүктеу | Download оқиғасы қабылданды; CSV тексеруден өтті |
| Синтетикалық деректе екінші толық есептеу | Алты CSV байт бойынша бірдей |

Нақты шығыс: `nodes_roles` — 2248, `clusters` — 88, `top_nodes` — 20,
`node_metrics`, `node_insights`, `ranking_stability` — әрқайсысы 2248 жол.
19 оқшауланған клиент жоғалмайды. 64 салмақ нұсқасы кінә ықтималдығын есептемейді.
Уақыт — осы компьютердегі бір өлшем; басқа компьютерге кепіл емес.

README-дегі негізгі пайдаланушы сценарийі жаңа көшірмеде API-сіз орындалды.
Сайт уақытша `127.0.0.1:8502` портында ашылды; негізгі жұмыс сайтына өзгеріс
енгізілген жоқ. Орнату, деректердің орналасуы, тексеру, ЖИ баптауы және
шектеулер README-де бар. Тексеру кезінде жергілікті `main` мен GitHub-тағы
`main` бір commit-ке көрсетті, жіберілмеген код өзгерісі болған жоқ.

Тесттер: рөлдер мен score, gid дәлдігі, кластер мүшелігі, топ-лист,
себеп/шектеу/келесі қадам, тұрақтылық, түйінді алып тастау, CSV келісімі,
қайталанғыштық, жетіспейтін/қате файлдар және чат тарихын тазарту.
Автотесттер нақты деректерді қажет етпейді; CI-ге бастапқы Parquet жіберілмейді.

## Қосымша ЖИ интеграциясын тексеру

ЖИ қосылған нұсқаның **48 тесті** жұмыс ортасында да, жоғарыдағы таза
GitHub көшірмесінде де өтті. `pip check` қайшы тәуелділік таппады.

`checks/test_llm.py` OpenAI/NVIDIA сұрау пішімін, құпия кілттің контекстке
түспеуін, timeout/HTTP қателерін, жарамсыз JSON/сілтеме/gid қабылдамауын,
бес клиент шегін және ортақ тікелей алушылар есебін тексереді.
`checks/test_interface.py` ЖИ чатындағы жауап, дереккөз, контекст және
сессия кілтін өшіруді де тексереді. Автотесттер HTTP жауабын mock арқылы береді;
нақты кілт, интернет немесе API кредиті қажет емес.

Нақты деректе екі клиенттің ортақ тікелей алушысы, сол клиенттерден келген
жалпы сома және транзакция саны жергілікті есептелді. Контекст құру қатесіз
аяқталды. Толық салыстыру синтетикалық fixture арқылы автотестте орындалады;
нақты клиенттердің қаржылық мәндері бұл есепте жарияланбайды.

Браузерде нақты OpenAI `gpt-4.1-mini-2025-04-14` моделімен екі сценарий өтті:

1. Клиенттің тексеру себептері, сомалары, дерек шектеулері және келесі қадамы
   қазақша түсіндірілді; `[N1]` сілтемесі CSV карточкасына сәйкес болды.
2. Екі клиенттің ортақ тікелей алушысы сұралды. Жауаптағы алушы gid-і,
   жалпы сома және аударым саны жергілікті `build_context` есебімен сәйкес болды;
   `[G1]` дереккөзі және таңдама шектеуі көрсетілді.

Біріктірілген `[N1, G1]` сілтемелері де қабылданады. Модель қолжетімді, бірақ
мәтінде қолданылмаған дереккөзді тізімге қосса, экранға тек нақты сілтемеленген
дереккөздер шығарылады. Белгісіз және тізімде жарияланбаған сілтемелер қабылданбайды.
Бұл мінез-құлыққа регрессиялық тест қосылды.

Алдыңғы жарамсыз кілт пен жарамсыз жауап кезінде offline карточка дұрыс
көрсетілді. Тірі NVIDIA шақыруы тексерілмеді; оның HTTP келісімі mock арқылы
қамтылған. Екі сәтті ЖИ сынағы барлық сұраққа дұрыс жауап беруге кепіл емес.
